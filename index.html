🛡️ Risk Register
Hallucination
Invented clause/value/date → Evidence required; dates by code
Missed Clause (False Negative)
Rule engine for numeric; recall tracked; sampling audit
Prompt Injection
Contract text as data; no outbound tools for extraction; schema validation
Data Privacy Breach
DPA with model provider; redact PII; encryption; role-based access
Automation Bias
Show evidence next to flags; random deep-review sampling
Model/Service Outage
Fallback to manual queue; abstraction layer; data export
Wrong Deadline
Deterministic date code with unit tests; HC4 human confirmation
Bias / Unfair Outcome
Uniform playbook rules; review override stats by vendor type

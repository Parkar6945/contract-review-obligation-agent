## 📌 Executive Summary

Manual contract review and obligation tracking in mid-sized commercial organizations is vulnerable to cognitive fatigue, slow cycle times (approx. **4 hours** per first-pass review), and costly leakage due to missed notice windows (est. **6%** of dated obligations missed/late; ~**9%** annual contract value erosion per WorldCC benchmarks).

This project designs and implements an **Agentic AI Supervisor-Worker Architecture** composed of five specialized agents:
1. **Supervisor Agent**: Plans, delegates, routes, retries, and enforces human-in-the-loop approvals.
2. **Intake & Classification Agent**: Classifies agreements (SaaS, MSA, Supply, Services), detects counterparties, and checks document structure.
3. **Clause Extraction Agent**: Extracts 9 critical commercial fields + dated commitments, citing quoted textual evidence and confidence scores.
4. **Risk Review Agent**: Checks extracted parameters against a 6-rule Corporate Legal Playbook (`R-PAY`, `R-NOTICE`, `R-LAW`, `R-LIAB`, `R-INDEM`, `R-DPDP`) and assigns severity tiers (`HIGH`, `MEDIUM`, `LOW`).
5. **Obligation Tracker Agent**: Computes non-renewal deadlines (`End Date − Notice Window`), assigns accountability roles, and triggers alerts (`PAST DUE`, `DUE <=30d`, `DUE <=90d`, `UPCOMING`).

The base-case financial model yields a **70.3% ROI** across two operating years with payback achieved in **10.5 months**.

## 🏛️ System Architecture

```mermaid
flowchart TD
    User([User: Legal / Procurement / Finance]) --> UI[Web Interface & Review Queue]
    UI --> Gate{Human-in-the-Loop Gate<br/>HC1: Legal | HC2: Manager | HC3: Low-Conf | HC4: Obligation}
    Gate --> Supervisor[Supervisor Agent<br/>Orchestration, Routing, Retry & Escalation]
    
    subgraph Workers [Specialist Worker Agents]
        Supervisor --> Intake[Intake & Classify Agent]
        Supervisor --> Extract[Clause Extraction Agent]
        Supervisor --> Risk[Risk Review Agent]
        Supervisor --> Tracker[Obligation Tracker Agent]
    end
    
    subgraph Stores [Storage & Knowledge Layers]
        Intake <--> Store[Contract Store]
        Extract <--> Vector[Vector Index / Playbook RAG]
        Risk <--> DB[(Obligation DB & Playbook Rules)]
        Tracker <--> Audit[(Audit Log & Notification Engine)]
    end
```

## 💻 Quickstart: Running from GitHub

### 1. Prerequisites
- **Python 3.10+** (Python 3.11, 3.12, or 3.13 supported)
- Standard library only — **no third-party pip dependencies required**!

### 2. Clone the Repository
```bash
git clone https://github.com/<your-username>/contract-review-agent.git
cd contract-review-agent
```

### 3. Generate Contracts & Ground Truth
```bash
python gen_contracts.py
```
*Creates the 10 contracts in `contracts/` and outputs `ground_truth.json`.*

### 4. Execute the Multi-Agent Pipeline
```bash
python agents.py
```
*Runs the supervisor, extraction, playbook review, obligation tracking, and outputs artifacts to `out/`.*

### 5. Run the Automated Evaluation Suite
```bash
python evaluate.py
```
*Scores the pipeline on tests T1–T6 against the ground-truth benchmark and prints the report.*

### 6. Launch the Interactive Web Dashboard
```bash
python dashboard.py
```
Open your browser and navigate to:
👉 **[http://localhost:8050](http://localhost:8050)**

Alternatively, you can open `index.html` directly in any modern browser to view the interactive dashboard with zero server setup!

## 🛡️ Governance, Risk & DPDP Act Alignment

- **Autonomy Tiers**:
  - **Autonomous**: Extraction, deadline arithmetic, internal drafting, and audit logging.
  - **Needs Human Approval (Gate)**: Contracts with `HIGH` severity flags (unlimited liability, absent DPDP clause), registration of external obligations, or policy alterations.
  - **Prohibited**: Direct counterparty interaction, unilateral modification of agreements, or automated contract execution.
- **DPDP Act 2023**: Purpose limitation, zero training on counterparty data, mandatory data-protection clauses, and breach-notification verification.
- **NIST AI RMF**: Mapped across all four core pillars: *Govern*, *Map*, *Measure*, and *Manage*.
